Merge — add as many PDFs as you like. They stack in the order shown under Files; use the arrows to reorder.

Tie a figure — pick the reference tool, click the balance in the balance sheet, then click the same balance in the bank statement. Both get mark 1. Click any mark to jump to its pair. The number rolls forward automatically once a pair is complete.

Status — green means the mark appears twice or more, amber means it is still one-sided.

Comment — the comment tool drops a sticky note you can type in and drag. The box tool circles a figure.

Keys — V, R, C, B to switch tools. Delete removes the selected mark. Esc goes back to select.

Save — "Save workpaper" writes one .wpaper file holding the PDFs and every mark, so you can reopen and carry on, or pass it to a reviewer. "Export marked PDF" burns the marks into a normal PDF for the client.

Everything runs inside this browser tab. No file is uploaded anywhere.
